# Unicode NFD Highlighter

A Sublime Text plugin that highlights text containing decomposed Unicode characters (NFD).

<img width="610" height="454" alt="s" src="https://github.com/user-attachments/assets/0952d349-95d6-4468-9ed9-474b64376832" />


Requires Sublime Text 4, build 4205 or later.

## Install

Open the Command Palette with `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (macOS), choose **Package Control: Install Package**, then select **Unicode NFD Highlighter**.

## Highlighting

NFD text is highlighted automatically when a file is opened or edited.

## Additional Commands

- **UnicodeNfdHighlighter: Check File** — manually scan and highlight NFD text in the current file.
- **UnicodeNfdHighlighter: Convert to NFC** — normalize the current file to NFC.
